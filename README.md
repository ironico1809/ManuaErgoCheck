# Guía de uso de ErgoCheck AI

Sitio estático independiente para consultar el manual por perfil. No necesita instalar dependencias ni conectarse al sistema para funcionar.

## Abrir en tu computadora

Abre `index.html` en un navegador. Conserva `styles.css`, `app.js`, `tutorial.js` y `asistente.js` en la misma carpeta.

## Subirlo a internet

Sube los cuatro archivos `index.html`, `styles.css`, `app.js`, `tutorial.js` y `asistente.js` a la carpeta pública de tu servicio de alojamiento estático. Configura `index.html` como página de inicio. También puedes subir la carpeta completa y acceder a su dirección correspondiente. No requiere base de datos ni servidor de aplicación.

La guía describe la interfaz disponible al momento de su creación. Revisa `app.js`, `tutorial.js` y `asistente.js` para actualizar pasos, pantallas y preguntas si el sistema cambia. El contenido es orientativo y no sustituye las políticas de tu organización ni una evaluación profesional.


El asistente busca respuestas en las guías locales mediante palabras clave. No usa inteligencia artificial generativa ni consulta información de cuentas; actualiza las guías en `app.js` cuando cambie el sistema.
